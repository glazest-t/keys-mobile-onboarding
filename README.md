# Ключи — два варианта онбординга

Пересобрано по изображению «Снимок экрана 2026-10-22 в 12.34.16.png».

## Открыть

Опубликованный прототип: https://glazest-t.github.io/keys-mobile-onboarding/

- [Вариант 1](https://glazest-t.github.io/keys-mobile-onboarding/onboarding-variant-1.html)
- [Вариант 2](https://glazest-t.github.io/keys-mobile-onboarding/onboarding-variant-2.html)

`index.html` — главная страница с двумя кнопками выбора. Для тестирования отправляйте участнику прямую ссылку на `onboarding-variant-1.html` или `onboarding-variant-2.html`. На страницах вариантов нет переключателя, ссылки на главную или на другой вариант. Вариант закреплен за страницей; параметр `variant` не может его изменить.

Для запуска без сервера: `prototype.html` — страница выбора; `prototype-variant-1.html` и `prototype-variant-2.html` — два независимых автономных файла со встроенными изображениями, стилями и шрифтами. Участнику можно отправить только один файл.

Для разработки запустите из этой папки:

```sh
python3 -m http.server 4188 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4188/ .

- `onboarding-variant-1.html` — верхний ряд референса.
- `onboarding-variant-2.html` — нижний ряд референса.
- `onboarding-variant-2.html?step=2` — ссылка на конкретный шаг второго варианта.
- Старые ссылки `/?variant=1` и `/?variant=2` автоматически перенаправляются на нужную независимую страницу.

## Состав флоу

| Шаг | Вариант 1 | Вариант 2 |
|---|---|---|
| 1 | Ваш ключ к любому отелю — карточки «В городе / У моря» | Поездка под контролем — номер 412 |
| 2 | Скидка отеля + баллы «Ключей» — 2 400 баллов | Две выгоды в одной брони — −15% и −4 860 |
| 3 | Отели, которые подходят вам — карточка отдыха у моря | Отели под вас — совпадение 92% |

Кнопки «Дальше», «Назад», «Пропустить», «Сначала», индикаторы второго варианта, клавиши ← → и горизонтальные свайпы работают. Перезапуск остается внутри назначенного варианта. Финальные CTA показывают конец прототипа и выбранное направление: поиск отеля или существующая бронь. Сами поиск и управление бронью не входят в эти шесть экранов.

## Исходники

- `app/landing.js`, `app/landing.css` — выбор на главной и совместимость старых ссылок.
- `app/prototype.js` — навигация внутри закрепленного за страницей варианта.
- `app/prototype.css` — общая оболочка и адаптивность.
- `app/screens.js`, `app/screens-v2.js`, `app/variant-one.css` — оригинальные блоки первого оформления.
- `app/variant-two.js` — экраны o4 → o2 → o6, извлечённые из исходного Design Component.
- `assets/`, `fonts.css` — локальные изображения и шрифты.

После правок пересоберите автономный файл:

```sh
node scripts/export-standalone.mjs
```

Для статического хостинга достаточно `index.html`, двух `onboarding-variant-*.html`, папок `app/`, `assets/` и `fonts.css`. Для автономной версии разместите вместе `prototype.html` и оба `prototype-variant-*.html`.
